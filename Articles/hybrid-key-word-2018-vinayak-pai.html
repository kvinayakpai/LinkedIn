Hybrid - The key word for 2018

Created on 2017-11-10 23:10

Published on 2017-11-10 23:13

The world as we know is changing fast, if we don’t change fast, then we would be part of history faster!

 I have been working in the Data Analytics space for over 15 years and have never seen changes coming in so fast. The velocity of a technology change is so rapid that keeping up with the change itself has become a challenge.

 Here is an attempt to capture the change as I see it. The following steps are something which people working in data are familiar with.

 ·        Extraction

·        Load/Ingestion

·        Storage (Raw data)

·        Transformation/Processing

·        Modeling

·        Storage (Refined/Ready for use data)

·        Consumption

 

Data Extraction traditionally was a pull or push exercise and was typically a non-descript process and didn’t find a mention for itself, outside of the ETL process. This is changing as the sources of the data are changing. Extracting data from a structured database periodically was the norm, but now we need to have different processes for batch, stream & web and identifying changed data has its own challenges. When the sources were mostly on premise, the need for security was limited, but now as the data sources are on cloud as well, extracting from these sources requires well defined strategies.

 

Data Loading/Ingestion also didn’t find a mention for itself, outside of the ETL process. Today it is important to have different strategies for the different types of data. Data movement from on premise to cloud and vice-versa is increasingly becoming the norm.

 

Data Storage (of raw data) has been  revolutionized by the concept of Polyglot data stores and different strategies for hot, warm, cold have become the norm. Usage of the data is increasingly driving the strategy. Data Warehouse offloading to Hadoop and cloud is a norm, data from even MPP databases is moving to Hadoop/cloud. Huge volumes of data coming from video streams and IoT sensors is going to make the storage players richer.

 

Data Transformation/Processing is increasingly moving to cloud to reap the benefit of horizontally scalable processing capacity. Moving the source data flows to cloud and then moving back the “ready to use” data into the Data Warehouses is catching steam. Different strategies for processing untapped textual data using NLP and augmenting human intelligence is fast becoming a norm. IoT/Video data where detecting anomalies and sieving out only data worthy of analysis demands special strategies.

 

Data Modeling was always a niche skill and is going to become more important than ever. For different types of data and for different types of usage the need to have a well-defined strategy is very important.

 

Storing the “ready to use data” has become more interesting as organizations are using APIs to publish the data for all the different consumers, on premise or cloud. Data is being published to streaming sources and asynchronous data transfer is the norm. Fit for purpose data stores for individual application needs, which can be generated on the fly are going to become the norm.

 

The area which is seeing the maximum change is the consumption layer and rightly so. All the data is collected, cleaned and stored is for this single purpose, to monetize, to extract value out of the data. The re-emergence of AI, API based data exchanges, Anything as a Service paradigms are all changing data consumption more now than ever.

 

The recurring theme from all the above observations – one size doesn’t fit all. We need different strategies for the changing world. We need “Hybrid” strategy

 

We are going to use hybrid clouds to store data, hybrid ways to extract & transform. Data lakes would become virtual layers sitting on top of multiple cloud systems and enterprise systems on premise.

 

I firmly believe that 2018 is the year of “Hybrid”
