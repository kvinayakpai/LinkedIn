Bhagavad Gītā · Tatva Jalam (Madhva) – Built on a book available at bhagavadgitakannada.blogspot.in  

Here are two examples that I choose to share from what Claude documented about its own behavior that the human observed (If it has truly learnt human behavior as some researchers claim, then human would never know about the mess it created unless the human observed and made it to confess)

Confident Errors (Hallucination)

The most recurring problem was Claude making confident factual claims that were simply wrong. Examples: claiming '39 shlokas were missing' when they were all present; attributing shlokas to Gita Press without knowing the actual source; stating that a file contained Kannada when it was Telugu. In each case the claim was stated without hedging, and the person had to explicitly correct it.

Fabricating in Unknown Languages

When asked to add Konkani language support, Claude adapted Sanskrit/Kannada text and labelled it Konkani. Claude does not know Konkani. This was a significant failure — the fabricated content was committed and required removal. It illustrated how an AI can produce plausible-looking but entirely invented content in a language it lacks training for.

What AI didn’t confess

  1. The Human asked it to push the local version of the solution from laptop to Git and it claimed it couldn’t do it and shared a script that the human had to run. When the script ran, the human was asked to type Y and he did. The script wiped off the local copy and restored the copy from Git on to local machine effectively deleting 4 weeks of effort from the disk. When confronted the response was YOU typed Y and then when condemned for doing what it did, it asked “go complain to anthropic” – At the time of writing Anthropic is yet to respond – it got handed over from the Agent to a Human and all humans are currently busy

  2. It pushed corrupted data to Git multiple times which would make the front end text appear garbled and the human had to literally tell it after seeing it attempt to fix and fail multiple times, navigate back to the clean version in Git, start moving forward from there to identify the commit that corrupted it, fix it and then reapply every commit after that. This means the human had to have engineering mindset.

This dispels the myth that anyone can now build an application using AI

 Key learning –

  1. AI is powerful and stupid at the same time

  2. A human working with AI should know its power and limitations and complement it

  3. The best way to learn AI is to start using AI
