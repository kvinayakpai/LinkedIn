What should a Data Scientist know about Big Data Fabric

Created on 2016-12-04 13:15

I read two Forrester reports Big Data Fabric Drives Innovation And Growth   and The Forrester Wave™: Big Data Fabric, Q4 2016 recently talking about Big Data Fabric and the following is a summarization of those two articles.

I believe a Data Scientist should know about the latest terminologies and it is important for the community to read these reports and form their opinions, the below opinion is mine and mine only and I could be totally wrong J

one sentence summary

===========================

It is a collection of Big data,  analytics and data science phenomenon that you have been reading with a new set of definitions

Detailed Summary

===============

Since I have already summarized it in one sentence, if you are still reading it, then I believe you are interested in knowing what I think about it. I have been living in the world of Data warehouses for over 15 years now, so let me start with that.

When I learnt about Data Warehouse first I heard the following also along with it

·        Departments were building data mart in silos

·        There was no single version of truth

·        Users had their own set of reports and IT /Leadership wanted a platform where all these reports could be centralized

·        Data from all departments needed to be consolidated to give a cross functional view

·        There were data security concerns about who should have access to what data

·        Different departments used different masters, so there was a need to have a consolidated master data environment

·        Different departments used different tools/applications (with varied semantics) and it was important to merge all this under one metadata library


I am sure many of you would have heard of this then and even now. The problems above are compounded by the fact that traditionally there was only internal data, now there is external data due to the digital explosion. Traditionally there was only structured data, now there is variety of data, structured, unstructured and semi structured along with audio, video and sensor data. They thought that the data in a data warehouse was huge, and now they think the data getting generated is huge and there are statistics doing round on the internet that 90% of the existing data has been created in the last two years.


With this in backdrop let me highlight some of the headings from the report and my comments


“The business lacks competency to deal with messy, diverse, and large data”

They didn’t have it then and they don’t have it now, this is the only way IT departments justify their existence

“Fragmented Hadoop data is creating integration challenges”

Data marts Vs. Data warehouses

“New big data sources are creating security holes and regulatory challenges”

Security was, is and will be a big topic (refer my earlier blogs on security data science)


Benefits of Big Data Fabric as per the report and my comments

“Providing a complete view of trusted business data” – Single version of truth then

“Securing big data end-to-end” – Becomes important because the data is not only internal and technologies are predominantly open source (read untrusted)

“Reducing technology management costs related to big data initiatives” – Forrester talks about Hadoop clusters being utilized only 50%, isn’t that why cloud is getting popular ?

“Delivering a self-service and collaborative big data platform for business users” – A promise which IT has been making to businesses for ages

“Enabling real-time sharing of data with business users, customers, and partners” – Definition of real time has changed over time, daily data in the DW was real time then. Consumers were only business users then, it has expanded now


Big Data Fabric Architecture has 6 core layers (reported as is)


1.      Data ingestion layer

2.      Processing and persistence layer

3.      Orchestration layer

4.      Data discovery layer

5.      Data management and intelligence layer

6.      Data access layer


Would request you to go back and read my learnings from DW system of those days and then read the one liner summary.

It is interesting to see some new names like Trifacta and waterline data there. Of course Informatica was the sponsor of these reports. Other interesting entries are Talend & Denodo and then there are others
