You think you can't be a Data Scientist - be a Citizen Data Scientist

Created on 2015-09-13 12:38

Published on 2015-09-13 12:44

In one of my earlier blogs I had written that Data Scientists

  • Use the ability to find and interpret rich data sources
  • Manage large amounts of data
  • Overcome constraints around hardware, software, and bandwidth
  • Merge data sources
  • Ensure consistency of data sets
  • Create visualizations to aid in understanding data
  • Build mathematical models using the data
  • Present and communicate the data insights/findings to specialists and scientists in their team and if required to a non-expert audience.

 

Over years organizations have found that finding Data Scientist who matches all of these (and more) criterion is very difficult. Data Scientists are hard to find, they are pricey, they are difficult to manage and more difficult to retain.

 Data Scientists on the other hand complain that organizations do not have clean data, no clear understanding of the data, segmented knowledge of its own business processes and its nuances, not enough man power or knowledge workers to prepare data for analysis, which makes them spend as much as 80% of their time in data related activities, becoming data janitors instead

 http://www.nytimes.com/2014/08/18/technology/for-big-data-scientists-hurdle-to-insights-is-janitor-work.html?_r=0

 In short – Organizations are in need of people who can aid the Data Scientists.

In the recent Hype Cycle, available at  http://www.gartner.com/newsroom/id/3114217, Gartner talks about Citizen Data Scientists

“Citizen data science is a branch of data science that allows users to extract advanced insights from data while not requiring the users to be highly skilled. Central to citizen data science are rapidly progressing tools that streamline data preparation, provide strong user guidance around the different data science operations (correlations, clustering, predictions) and often automate various modeling and pattern-detection steps on the user's behalf.”

“For every new data scientist hired, companies can enable five knowledge workers to implement their own self-service citizen data science by using modern analytic tools.”

So, if you think you can't be a Data Scientist - be a Citizen Data Scientist

What skills do you need?

Here is what I think

  • Ability to work with data
  • An eye of finding patterns in data
  • Very good knowledge of Excel and related power BI tools
  • Knowledge of data management language like SQL
  • Knowledge of programming languages like Java, Python
  • Knowledge of statistical languages like R
  • Knowledge of Linux/Unix scripting
  • Knowledge of java scripting which will enable them pick up D3.JS
  • Ability to pick up new programming language

 

Well, this is just the beginning, but knowing these would allow you to become a Citizen data scientist and then graduate to become a Data Scientist

 So who would be hiring Citizen Data Scientists?

 Organizations which have Data Science projects (which would be almost every other organization pretty soon)

 So what is stopping you, set sail and start the journey which would take you from the data pool you are in , into the data lake (or the data landfill) and then into the data reservoir and into the big ocean of data.

 

P.S – Be prepared to survive the sewage (data quality problems) coming into the data lake which will follow you all the way to the ocean. If you are not prepared, then you would be like the dwindling population of fish
