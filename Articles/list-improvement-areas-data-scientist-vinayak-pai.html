List of Improvement Areas for a Data Scientist

Created on 2017-03-27 02:59

Published on 2017-03-27 03:02

As you know the Appraisal season is on :)

While I was writing Improvement Areas for my set of Data Scientists, I felt these are relevant to each one of us. Hence sharing with you all. Please use if it is relevant

1.      Big/New data skills/cloud platforms – The future of Data Science requires these skills and you should make conscious attempts to pick up these skills

2.      Communication / Presentation / Story telling – This is an area of continuous improvement for all of us. I believe you can keep working on this and build it to a level where customers would be engrossed in the story and enjoy the experience

3.      Database/RDBMS/SQL/ Data Engineering/Data Wrangling – You should try and build hands-on capabilities in the new age tools which would come in handy when managing teams

4.      Domain Knowledge/Business Processes – This is one of the key skills required for a Data Scientist. It would help you appreciate the customer’s business problems and come up with effective solutions

5.      Exploratory Data Analysis / Visualization – You should consciously attempt to learn one visualization tool as this enables you get into spontaneous discussions using visualization during customer interactions. I have seen that this is a very effective mode of communication and customers love it

6.      Machine Learning/Deep Learning/ Cognitive Computing (SPARK-ML, Azure ML, API based programming, Deep Learning, Cognitive computing) – You should work on building your skills in this area and at least be equipped to have meaningful conversations with the customers. If possible proactively seek opportunities to implement solutions using newer technologies      

7.      Mentoring – A successful Data Scientist of the future would be identified by the number of people inspired and guided by them, so I believe this is a key skill that you should consciously develop

8.      Problem Identification and scoping – As a Data Scientist, you would be facing newer problem statements and you would need to be able to scope out a small solvable problem which can then be worked upon

9.      Process – You should make conscious attempt to document the process followed in your work, and work in the direction of converting the art of Data Science into a skill/science which can be imparted to others easily            

10.  Project Management – Understand the roles and responsibilities of a Project Manager from a Data Science angle

11.  Statistics/Mathematics (SQL/R/SAS/SPSS/Python/Scala/Spark) – You should pick up the skills like Python, Spark and cloud technologies and develop ability to scale a Data Science solution using these technologies. At least keep reading on these topics to keep yourself informed enough to have meaningful conversations with technical stakeholders in the customer organization

12.  Strategy – You should work on identifying future areas of work and wear the innovative hat in-order to develop winning strategies for the organization. You should think of solution that can be flag bearer for your organization. You should think of ways in which you can help your organization get ahead of the competition and more importantly itself

13.  Proposal building / Solution Design / Technical Estimation / Planning – While this might appear to be a “non-Data Scientist” type of work, increasingly it is becoming important that you develop these skills for effective stakeholder management. It gives you a tremendous kick when you see a project from proposal/planning stage to implementation stage

Would be curious to know if you would have added something to the list
