SQL is the tool most used in Data Science and helps people get paid more

Created on 2016-07-07 08:05

Published on 2016-07-07 08:09

Let me start with the surprise find that I had “SQL is the tool most used in Data Science”. I am sure you would have been shocked by the subject, and I was too when this came upon me. Came across a Data Science salary survey report from Oreilly and another one on data science central (links provided below)

 Here are the key findings of the Oreilly report

The same four tools—SQL, Excel, R, and Python—remain at the top for the third year in a row

  • Spark (and Scala) use has grown tremendously from last year, and their users tend to earn more
  • Using last year’s data for comparison, R is now used by more data professionals who otherwise tend to use commercial tools
  • Inversely, R is no longer used as frequently by data practitioners who use other open source tools such as Python or Spark
  • Salaries in the software industry are highest
  • Even when all other variables are held equal, women are paid thousands less than their male counterparts
  • Cloud computing (still) pays
  • About 40% of variation in respondents’ salaries can be attributed to other pieces of data they provided

When you go through the complete report you would find

  • 68% of the sample use SQL
  • 59% use Excel
  • 52% use R
  • 51% use Python

But as per this report if you look at the Salary, you would find that people with Scala getting paid the most.

There was an interesting line in the report “learning Spark could apparently have more of an impact on salary than getting a PhD. Scala is another bonus: those who use both are expected to earn over $15,000 more than an otherwise equivalent data professional.”

So if you were to know SQL + Excel + R + Python + Scala + Spark – you would be having a nice combination of skills.

Then there was an interesting line about D3JS – “It appears that either data scientists are being paid more for having this skill, or the ones who already make more tend to choose the D3 path.”

And then there was one more piece – “Not only is there a positive amount attributed to using cloud computing for most or all applications, there is an even more significant penalty for those who do not use any cloud computing”

So the combination of skills would be SQL + Excel + R + Python + Scala + Spark + D3JS + Cloud

There was some other interesting observations that could be made from the report

57% of the people surveyed said they spend up to 4 hours a day on ETL  and interestingly around 5% of the respondents who earn most (120K+) spend more than 4 hours a day on ETL.

 There are other interesting graphs on how much time do they spend on Data Cleansing, EDA Visualizations, presentations and meetings and how valuable bargaining skills are, but I would not get into those details, but conclude my observations from this report with one last chart

As you can see from the above picture, only 10% of the (highest paid) people working in Data Science are spending more than 4 hours a day on ML and Statistics. Which kind of supports my theory that while Statistics is important , Data Science is much more than just Statistics where the rest of the surveyed professionals seem to be spending their time.

Let me now talk about the another analysis from Data Science central which focused only on R, Python and SQL

The analysis they did was in San Francisco based on advertisements for the post of architects and software engineers, and not just data scientists.

 Here are two interesting observations they make

 “It seems, if this data is correct, that SQL commands higher salaries than R, contrarily to my intuition. These numbers, based on recent job ads, can be found here (you can select the skill or location). “

“Sounds like Python + SQL might be the best combination. What is weird is that Python + R seems to command a lower salary than just Python alone. And if you know SQL, it gives you a nice boost if you are an R programmer.”

 I started off by making a statement that “SQL is the tool most used in Data Science”, but based on this analysis I am tempted to state “SQL is the tool most used in Data Science and helps people get paid more”

 

In summary 

  • SQL, Excel, R, and Python are the most used tools in Data Science
  • Spark, Scala, D3JS and Cloud add to the mix and make it very potent
  • Not working on cloud could make your profile less attractive
  • R is now used by more data professionals (over commercial tools)
  • There is an increasing usage of Python and Spark compared to R
  • Women are paid less than their male counterparts (While this is across the industry and comes in every report, situation remains the same)

 

In conclusion as a Data Scientist you should know all these tools to be paid high SQL + Excel + R + Python + Scala + Spark + D3JS + Cloud.

 

P.S. I have been working with data (& SQL) for close to 18 years now, so it is heartening for me to know that SQL is the tool most used in Data Science. However the cautionary note is that not everyone who have SQL on their profile know SQL. Few years back I was trying to build a team for working on customer behavior analytics using SQL. 9 of the 10 people who have SQL on their profile could not join two or more data sets satisfactorily and get the desired output. Most of the people were tool oriented and used to rely on a tool to combine data sets to extract juice out of it. So when I was thinking of SQL above, please note that it is “Very good knowledge of SQL – almost bordering on expert levels”  that is required for Data Science and not the variety taught in any academic institution or even learnt by tool oriented data professionals.
